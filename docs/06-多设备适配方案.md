# 多设备适配方案（Cirrus / 卷云）

> 目标设备：手机、平板、折叠屏、智能手表、电脑（PC）、电视（TV）。
> 原则：一套响应式代码覆盖大屏，手表独立轻量入口，跨设备数据一致。

## 1. 设备矩阵与能力边界

| 设备 | 屏幕形态 | 输入方式 | 关键 Kit | 适配策略 |
|------|----------|----------|----------|----------|
| 手机 | 直板/折叠(外屏) | 触控 | 全量 | 基准布局 |
| 阔折叠（如 Pura X）| 展开/外屏比例特殊 | 触控 | 全量 | ⚠️ 外屏比例特殊，**无法**靠一套布局自适应，需单独 UX + 断点分支 |
| 折叠屏 | 展开 7–8" | 触控 | 全量 | 断点切换为平板布局，避免拉伸 |
| 平板 | 10–13" | 触控/笔 | 全量 | 主从（Master-Detail） |
| 电脑 PC | 桌面窗口 | 鼠标/键盘 | 全量 | 主从 + 窗口自由缩放 |
| 电视 TV | 大屏 10′+ | 遥控器 D-pad | 全量(无定位) | 焦点导航 + 精简大字号 |
| 手表 | 圆形/方形 1–2" | 触控/表冠 | 受限 | 表盘并发症 + 极简卡片 |

> **部署模型（一次开发多端部署）**：手机/平板/PC/TV 属同一泛类→**模型 A**（相同 HAP）；手表属不同泛类→**模型 B**（独立 `watch/` HAP，见 11 §6.1）。能力差异须经 **SysCap/`canIUse`** 运行时判定（如 TV 无定位）。

## 2. 响应式断点定义

统一基于 `vp`（虚拟像素）与栅格（`GridRow`/`GridCol`）：

| 断点 | 宽度区间 | 典型设备 | 布局 |
|------|----------|----------|------|
| xs | < 320vp | 外屏/Pura X 外屏 | 极简单栏（单独 UX） |
| sm | 320–600vp | 手机竖屏 | 单栏，底部 Tab |
| md | 600–840vp | 折叠展开/小平板 | 单栏增强 / 可选双栏 |
| lg | ≥ 840vp | 平板/PC/TV | 主从双栏（列表 + 详情） |

- 使用 `mediaquery`（`@kit.ArkUI`）监听断点，切换全局断点信号驱动重排；`GridRow`/`GridCol` 栅格布局。
- 组件以「自适应参数」暴露：`WeatherCard({ compact: boolean })`，由父布局按断点注入，避免组件内硬编码尺寸。

## 3. 各设备布局策略

### 3.1 手机 / 折叠外屏（sm）
- 底部 `HdsTabs`（悬浮胶囊，`barPosition(BarPosition.End)` + `barOverlap(true)`）：天气 / 位置 / 设置。
- Home 单栏滚动：Hero → 逐小时横滑 → 多日 → 详情分组；标题栏经 `dynamicHideTitleBar` 上滑渐隐。
- 折叠展开（md/lg）自动切换为双栏，无需重启（保持任务连续性）。

### 3.2 平板 / PC（lg）
- `Master-Detail`：左列位置列表/多日概览，右列当前天气 + 逐小时 + 详情。
- 支持自由窗口：监听窗口尺寸而非仅设备类型，保证分屏/悬浮窗正确。

### 3.3 电视 TV
- 禁用滚动长页，采用 **焦点（focusable）卡片横竖网格**，遥控器方向键导航；`List/Grid.focusWrapMode` 控制走焦环绕。
- 大字号、高对比、远距离可读；不依赖精确定位（默认展示已添加城市或首个位置）。
- 首屏即「当前天气 + 今日/明日概览」大卡。
- HDS 底部页签**不支持 TV**，TV 底部/侧边导航需用 `HdsSideBar`（支持 TV）或自研焦点栏。

### 3.5 沉浸光感与悬浮导航（框架级适配）

以 **UI Design Kit（HDS）+ 沉浸光感** 统一全端视觉与交互（详见 `11` §2/§3）：

- 根路由 `HdsNavigation`/`HdsNavDestination`；标题栏 `systemMaterialEffect` + `ScrollEffectType`。
- 手机/平板/PC：`HdsTabs` 悬浮胶囊 + 智感握姿（`adaptToHandedness`）；宽屏可展开 MiniBar。
- 大屏：`HdsSideBar` 侧边栏承载位置列表，主区承载详情。
- **能力探测降级**：`deviceInfo.apiAvailable('26.0.0') && hdsMaterial.getSystemMaterialTypes().length > 0` 不满足时回退普通半透明卡片。
- **设备边界**：沉浸光感材质仅 Phone/Tablet；底部页签不含 TV；UI Design Kit 仅中国境内（出海走降级实现）。

### 3.4 手表
- **表盘并发症（Complication）**：显示当前温度 + 天气图标，一点即看。
- **极简卡片页**：温度、状况、今日最高/最低，可上滑看逐小时精简条。
- 复用 `data` + `common`，但 UI 独立（`watch/` 入口），避免引入大屏组件。

## 4. 响应式组件策略

| 组件 | 自适应做法 |
|------|------------|
| 天气卡片 | `compact` 标志切换密度；`GridCol` 跨列数随断点变化 |
| 逐小时图表 | 横滑容器，tv 改为焦点网格 |
| 多日列表 | sm 竖列表；lg 转栅格 |
| 图标/字号 | 跟随系统字体缩放 + 断点基准字号（`uiAppearance` 读取缩放比例） |
| 输入交互 | **交互归一**：触控/鼠标/键盘/遥控器统一事件；TV 走方向键走焦（`focusWrapMode`），PC 走 hover/右键 |

## 5. 跨设备同步（DistributedKV）

- **同步内容**：位置列表、默认位置、用户设置（主题/单位/源/语言）。
- **机制**：`DistributedKV` + 同华为账号 + 设备组网信任；写入即广播。
- **冲突策略**：以「最后写入时间」为准（LWW），设置变更低频，冲突概率低。
- **手表**：因受限，手表从手机同步位置后本地只读缓存，不回写。

## 6. 资源适配

- 图标/背景按 `resource` 限定词（`vertical/horizontal`、`sd/hd`）提供多分辨率。
- 大屏额外提供「电视焦点态」样式资源；手表提供圆形/方形两套布局。
