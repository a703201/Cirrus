# 应用命名方案（多语言）

> 参考对象：Breezy Weather（微风天气）、Geometric Weather（几何天气）。
> 命名目标：气象语义清晰、跨语种易读易发音、契合 HarmonyOS 极简美学、无显著商标冲突。

---

## 1. 命名策略

采用 **「单一全球品牌名 + 各语种本地化显示名」** 的双层策略：

- **品牌内核（Global Mark）**：一个短、易发音、跨拉丁语种一致的词，作为包名、图标、商店主标题的统一标识。
- **本地化显示名（Localized Display）**：在各语种商店/应用内展示时，使用对应语言的气象意象词，降低非英语用户认知门槛。
- **图标字标（Glyph）**：取一个单字/单笔意象（如「云」「霁」或拉丁字母 C）作为启动图标核心。

---

## 2. 候选命名系统（5 套）

### 方案 A —— Cirrus / 卷云（★ 推荐）

## 3. 推荐结论

**主推：Cirrus / 卷云（方案 A）**，备选 Zephyr / 微风（方案 B，若希望强化与 Breezy Weather 的传承感）。

理由：
1. 气象语义精准且中性，不绑定某一具体天气现象；
2. 跨拉丁语种拼写稳定，降低多语言品牌资产碎片化；
3. 视觉与 HarmonyOS 极简/通透美学高度契合；
4. 商标冲突风险低，可作为长期品牌资产沉淀。

**统一品牌 Mark**：`Cirrus`（全球商店主标题与包名统一）。
**中文显示名**：`卷云`（应用内与华语商店）。
**一句话 Slogan（多语示例）**：
- 中文：卷云 · 看清每一刻天气
- EN：Cirrus · Weather, beautifully clear
- JA：巻雲 · 天気を、美しく澄ませて
- KO：권운 · 맑게 보는 날씨
- FR：Cirrus · La météo, en toute clarté
- ES：Cirrus · El clima, con claridad
- DE：Zirrus · Wetter, klar und schön
