# 实施计划与功能优先级（Cirrus / 卷云）

> 版本基线：**0.1.0** ｜ 包名：**com.Lumio.Cirrus** ｜ 目标 API：**26** ｜ 依据：`03-PRD`、`10-研发计划`、`11-鸿蒙新特性与沉浸光感适配`

## 0. 原则

- **先闭环，再精致**：优先让「定位/搜索 → 展示 → 刷新 → 多位置 → 设置」端到端跑通（P0），视觉与鸿蒙新特性（沉浸光感/HDS）紧随其后（P1）。
- **原生优先 + 状态管理 V2 + Kit 化导入**：新代码统一 `@kit.*` 与 `@ComponentV2`。
- **每级可交付**：每一级独立可运行、可验收。

### P0 验收标准（v0.1）
1. 冷启动可读当前默认位置天气（缓存命中即时渲染，断网回退缓存并提示）。
2. 可搜索城市→添加→切换→删除→设默认；重启后位置与设置保留。
3. 主屏含当前/逐小时/多日/详情四段，手动下拉可刷新。
4. 源/单位(°C/°F)/主题(跟随/亮/暗)/语言可切换并持久化。
5. 手表可展示当前温度与状况。
6. `hvigor` 构建零 ERROR（需 DevEco Studio 实测）。

> 说明：P0 视觉采用**稳定的 `backgroundBlurStyle` 玻璃卡片**；`systemMaterial` 沉浸光感材质与 HDS 组件（`@kit.UIDesignKit`）在 **P1** 接入并做真机验收（见 `11` §2/§3）。

## 5. 本次实施范围（v0.1.0）

- 覆盖 P0-1 ~ P0-14。
- 定位：**个人开发者**项目——不依赖企业开发者专属能力（小艺意图框架 P2-4 暂缓）；和风 API Key、AGC 推送等为本机/自持配置。
- 交付：可编译的 v0.1 功能闭环 + 7 语种资源 + 手表入口。
- 验证：需在 DevEco Studio（API 26）执行 `hvigor` 构建与真机/模拟器自测。

## 6. 风险

| 风险 | 对策 |
|------|------|
| RDB/Preferences 首次落地方案差异 | 使用官方标准 API（`@kit.ArkData`）；失败降级内存缓存 |
| 离线/无权限场景 | 回退缓存 + 明确提示，不崩溃 |
| 沉浸光感/HDS 需真机与 SDK 验证 | P1 单独里程碑，先做能力探测与降级 |
| API 26 单一基线 | 能力探测（`deviceInfo.apiAvailable` / `canIUse`），功能降级 |
