# 设计规范 UI/UX（Cirrus / 卷云）

> 设计语言：**沉浸光感（空间化 Spatial UI）+ 动态天空主题**（基于 HarmonyOS UI Design Kit，致敬 Breezy/Geometric 的通透美学）。
> 目标：信息清晰、动效克制、全设备一致、无障碍友好。技术落地见 [11-鸿蒙新特性与沉浸光感适配](./11-鸿蒙新特性与沉浸光感适配.md)。

## 1. 设计语言

- **系统材质玻璃**：标题栏/导航用 HDS 沉浸光感材质（毛玻璃，内容隐约透出）；内容区卡片按需 `.systemMaterial(ImmersiveMaterial)`。**替代自研 `blur`**，避免双层模糊叠加（性能与观感）。
- **动态取色**：背景渐变与强调色由「当前天气状况 + 时段（昼/夜/晨/昏）」推导（如晴昼=暖蓝、雷暴=深紫灰）。
- **克制动效**：仅关键处使用动效（天气粒子、页面转场、数字翻牌），避免干扰阅读。
- **一致圆角**：卡片圆角统一 16–24vp，符合 HarmonyOS 圆角语言；悬浮导航为胶囊圆角。
- **光影语言**：适度使用点光源/边缘流光/按压阴影等系统级光影（详见 `11` §3.1），提升精致感但不牺牲效率。

### 1.1 材质档位（跟随系统 + 可切换）

| 档位 | MaterialLevel | 适用 |
|------|---------------|------|
| 强 | `EXQUISITE` | 高性能设备（亮色下注意覆盖白叠层） |
| 均衡（默认） | `GENTLE` | 视觉/性能平衡 |
| 弱 | `SMOOTH` | 低端设备 |
| 系统自适应（默认启用） | `ADAPTIVE` | 由系统按算力自动选择 |

- 默认 `MaterialType.ADAPTIVE` + `MaterialLevel.ADAPTIVE`；设置页提供手动档位切换。
- **降级**：不支持时回退普通半透明卡片（见 `11` §2.4）。

## 2. 色彩系统

### 2.1 语义色（随主题切换）
| 用途 | Light | Dark |
|------|-------|------|
| 背景基色 | #F5F7FA | #0E1116 |
| 卡片填充 | rgba(255,255,255,.65) | rgba(255,255,255,.08) |
| 主文字 | #1A1A1A | #F2F2F2 |
| 次文字 | #6B6B6B | #A0A0A0 |
| 强调色 | 动态天空蓝 #3B82F6 | 同明度调整 |

### 2.2 天气主题色（由状况+时段推导，示例）
| 状况 | 昼 | 夜 |
|------|----|----|
| 晴 | 暖蓝→金 | 深蓝→靛 |
| 多云 | 灰蓝 | 墨蓝 |
| 雨 | 青灰 | 深青灰 |
| 雪 | 冷白蓝 | 深蓝白 |
| 雷暴 | 紫灰 | 深紫黑 |

> 强调色优先用 `@StorageProp('isDark')` 驱动重渲染，普通方法取色触发响应（遵循项目主题规范）。

## 3. 字体与排版

- 字体：鸿蒙默认 `HarmonyOS Sans`（系统字体），不引入外部字体以控体积。
- 字号阶梯：Hero 温度 64–96vp；标题 20–24vp；正文 14–16vp；辅助 12vp。
- 字重：温度用 Light/Thin 显轻盈；标签用 Medium 提对比。
- 支持系统字体缩放（最大 1.5× 不破版）。

## 4. 图标规范

- **天气图标**：自绘 SVG/PDF，按 `wx_{code}_{day|night}` 键组织（见接口文档 §3.5）。
  - 线面结合风格，描边 2vp，单色可染色（随主题强调色）。
  - 提供 day/night 两套光影。
- **功能图标**：采用系统 `Symbol`/图标字体风格，统一 24vp 网格。
- **品牌图标**：卷云笔触 + 渐变天空，字标 `C` 或「云」。

## 5. 核心页面视觉规范

| 页面 | 视觉要点 |
|------|----------|
| Home（Hero） | 全屏动态背景 + 居中大温度 + 状况图标 + 位置/时间；下滑露出详情 |
| 逐小时 | 横滑卡片序列：时间 / 图标 / 温度 + 底部降水概率细柱 + 风羽 |
| 多日 | 行式列表：日期 / 昼夜图标 / 温区条（min–max 渐变柱） |
| 详情 | 分组玻璃卡：大气（湿度/气压/云/能见度）、风（速度/方位罗盘）、太阳月亮（升落/月相）、空气质量（AQI 色阶） |
| 位置管理 | 城市卡列表 + 搜索框 + 默认星标 + 拖拽排序 |
| 设置 | 分类全宽圆角卡（图标 + 标签 + 右箭头），Sheet 内嵌分页 + slide/fade 转场（沿用项目偏好） |
| 预警 | 等级色条卡片（蓝/黄/橙/红）+ 生效时段 |
| 卡片 Widget | 1×2/2×2/4×2 规格，复用 Hero 缩略版 |

## 6. 动效

- **天气粒子背景**：雨（斜线下落）、雪（飘落）、云（缓动漂移）、雾（模糊流动）——基于 Canvas，按状况+时段开关，注意耗电；**滚动/材质交互期间暂停粒子**（沉浸光感 GPU 开销叠加）。
- **数字翻牌**：Hero 温度刷新用 `Text.contentTransition`（数字翻牌动效），避免生硬跳变。
- **渐变文本**：Hero 温度可用 `Text.shaderStyle`（线性/径向渐变）增强表现力。
- **图标动效**：`SymbolGlyph` 支持阴影/渐变/快速替换动效，用于天气符号切换。
- **页面转场**：列表→详情共享元素（温度/图标）位移淡入；设置 Sheet 内页 slide + fade。
- **可选三维动效**：卡片按压可用 `transform3d` 轻微倾斜（克制度）。
- **无障碍**：`prefers-reduced-motion` 时关闭粒子与大幅动效，仅保留必要过渡。

## 7. 无障碍

- 最小对比度 4.5:1（文字/背景）。
- 所有图标配文字标签；天气图标加 `accessibilityLabel`（如「晴，24 度」）。
- 支持屏幕朗读、字体缩放、高对比模式；不依赖纯颜色传达信息（预警同时用文字/图标）。
