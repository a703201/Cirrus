# PRD 产品需求文档（Cirrus / 卷云）

> 参考：Breezy Weather、Geometric Weather ｜ 平台：HarmonyOS NEXT ｜ 文档版本：v0.1（规划稿）

## 1. 产品定位

**一句话定位**：一款离线友好、隐私优先、支持多天气源可插拔与全场景设备覆盖的精致天气应用。

**核心价值**：
- **通透美观**：动态天空主题、天气粒子背景、**沉浸光感系统材质**卡片与悬浮导航，信息层级清晰。
- **隐私优先**：默认端侧直连免密钥源（Open-Meteo），位置数据仅用于向天气源请求，最小化上传。
- **多源可插拔**：内置开放源，预留和风/彩云等扩展，用户可在设置切换。
- **全场景**：一套代码覆盖手机/平板/折叠屏/PC/TV，手表独立轻量入口，跨设备位置同步。
- **广泛多语**：首发 7+ 语种，架构预留 i18n 扩展。

## 2. 用户画像

| 画像 | 特征 | 核心诉求 |
|------|------|----------|
| 通勤上班族 | 每日固定出行 | 分钟级降水提醒、早晚通勤天气、预警推送 |
| 旅行/户外爱好者 | 多城市、出境 | 多位置管理、全球城市搜索、空气质量、紫外线 |

| 多设备鸿蒙用户 | 手机+平板+手表 | 位置/设置跨设备同步、手表快速查看 |

## 3. 用户场景

**场景 1 · 晨间通勤**
> 用户起床，手机锁屏卡片已显示「今日 18°C 多云，7:40 有零星小雨」。点开应用，逐小时图显示 8 点降水概率 60%，于是带伞。通勤前收到一条本地通知：「晚高峰降温至 14°C，注意添衣」。

**场景 2 · 出境旅行多城市管理**
> 用户将「东京、上海、巴黎」加入位置列表，平板端主从布局左列城市、右列详情，一键切换。所有城市数据经同一 Open-Meteo 源获取，无额外密钥。

**场景 3 · 隐私优先的本地天气**
> 用户关闭「精确定位」，仅授权近似位置；应用据此反查城市并展示天气，全程未向任何第三方上传精确坐标以外的信息。用户可在设置查看「数据流向」说明。

**场景 4 · 跨设备无缝**
> 用户在手机新增「公司」位置并设为默认；平板与 PC 打开应用即通过分布式 KV 自动出现该位置，无需重复添加。

**场景 5 · 极端天气预警**
> 台风临近，Push Kit 推送极端天气预警；应用内「预警」页汇总预警等级、影响时段与避险建议（建议文案为官方预警文本，应用仅做呈现与本地提醒）。

## 6. 非功能需求

| 维度 | 目标 |
|------|------|
| 冷启动 | 首屏可见 ≤ 1.0s（缓存命中），完整数据 ≤ 2.0s（网络正常） |
| 刷新 | 手动刷新 ≤ 1.5s（P95）；后台周期刷新每日 ≤ 4 次（省电） |
| 包体积 | 初始包 ≤ 25MB（自研图标/图表，无重型依赖） |
| 离线 | 断网可查看最近一次缓存（≥ 24h 有效），明确「缓存时间」标识 |
| 兼容性 | API 26；覆盖手机/平板/折叠/PC/TV，手表轻量 |
| 视觉品质 | 采用 HarmonyOS **UI Design Kit + 沉浸光感**，第一眼即系统级通透质感；低端设备优雅降级 |
| 无障碍 | 支持系统字体缩放、深色模式、屏幕朗读、最小对比度 4.5:1 |
| 隐私 | 位置仅用于天气请求；免密钥源默认；可关闭遥测（无遥测更佳） |

## 7. 验收标准（v1）

1. P0 功能 100% 可用，主流程（定位/搜索→展示→刷新→多位置）端到端跑通。
2. 默认源（Open-Meteo）在全球主要城市数据准确，WMO 代码映射无遗漏。
3. 手机 + 平板响应式布局无错位，折叠屏无黑边/重排异常。
4. 支持 zh-CN / en-US / ja-JP / ko-KR / fr-FR / es-ES / de-DE 切换且文案完整。
5. 离线可查看缓存；断网有清晰提示，不崩溃。
6. 通过 Hypium 单元测试（数据解析/映射/代码表）与核心 uitest 用例。
7. 隐私政策与权限申请说明完整，权限按需申请。
8. 沉浸光感在支持的 Phone/Tablet 真机上呈现完整效果，且在不支持设备/模拟器上**优雅降级不白屏**；宽屏智感握姿生效。
9. 使用 `@kit.*` 原生 Kit 与状态管理 V2，无 V1/V2 装饰器混用；不接入实况窗/意图框架等不适用能力。
