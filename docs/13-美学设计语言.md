# 美学设计语言（Cirrus / 卷云）

> 设计语言命名：**卷云·气象拟真（Atmospheric Realism）**
> 对标基准：Apple Human Interface Guidelines（HIG）之精神内核，并**在其之上改进**，形成本应用独有的设计哲学。
> 平台：HarmonyOS NEXT（API 26）｜载光引擎：**沉浸光感（空间化 Spatial UI）**
> 关联：实现级规范见 [08-设计规范UIUX.md](./08-设计规范UIUX.md)；技术可行性见 [11-鸿蒙新特性与沉浸光感适配.md](./11-鸿蒙新特性与沉浸光感适配.md)；优先级见 [12-实施计划与优先级.md](./12-实施计划与优先级.md)。

---

## 1. 定位与目标

天气应用的本质，是把「天空」带进用户的掌心。**卷云·气象拟真**的目标不是做一块"显示数据的界面"，而是**让界面本身成为这片天空**——温度、光线、色彩、材质、动效全部由真实的天气与时刻推导，界面像大气一样通透、因时因地而变。它要同时达成三件事：

1. **可信的真实感**：视觉与体感忠于当下天气（晴不刺眼、雨不压抑、雷暴有张力）。
2. **克制的优雅**：信息优先，界面让位于内容（苹果的 deference 精神）。
3. **有机的生命感**：光影、材质、数字都在"呼吸"，但从不喧宾夺主。

---

## 2. 设计哲学：卷云三信条

### 信条一 · 内容即天空（Content is Sky）
界面不是内容的容器，界面就是内容。首屏即一片天空，天气是唯一主角。所有的 chrome（导航、标题、卡片）都应是**半透明的介质**，让天空透过来，而非遮挡。

### 信条二 · 光即材质（Light is Material）
我们不"画"玻璃，我们让光穿过界面。材质不是贴图，而是**真实物理光照的模拟**——沉浸光感提供毛玻璃、按压点光源、材质流光、渐变模糊、智能反色。深/浅、前/后、虚/实皆由光表达，而非描边与阴影暗示。

### 信条三 · 随境而变（Ambient Adaptation）
同一套界面，在晴昼、雨夜、雪晨、雷昏下应呈现**不同的光与色**，却保持**一致的秩序与可读性**。变化的是氛围，不变的是结构与交互。

> 三信条合一的检验标准：**截图任意一屏，能一眼看出此刻是"何种天气、什么时刻"，且仍能毫不费力地读信息。**

## 3. 对标 Apple HIG：继承什么，改进什么

苹果的设计语言以 **Clarity（清晰）、Deference（遵从）、Depth（纵深）** 三大原则与「让内容说话」著称。我们**继承其精神内核**，并在"动态性、物理感、语境化"三个维度**向前改进**。

| 维度 | Apple HIG（继承） | 卷云·气象拟真（改进） |
|------|------------------|----------------------|
| 哲学 | Clarity / Deference / Depth | 保留三原则，叠加 **"Ambience（氛围即信息）"** 作为第四维 |
| 材质 | 通用材质（`.ultraThinMaterial` 等），静态、中性 | **沉浸光感**：材质含流光与点光源，且**随天气/时段呼吸**；由系统算力自适应分档 |
| 色彩 | 语义色 + 系统强调色，**静态**、与内容解耦 | **动态天空取色**：主色由「天气 × 时段 × 昼夜」实时推导，界面随天而变 |
| 纵深 | 阴影 + 模糊表达层级 | **空间化纵深**：前/中/后景 + 真实光衰减 + 智能反色（前景随背景自动调整可读性） |
| 排版 | SF Pro，Dynamic Type | HarmonyOS Sans + **数字翻牌（contentTransition）+ 渐变文本（shaderStyle）**，让"温度"成为可感知的图形 |
| 动效 | 物理弹簧、克制转场 | 物理弹簧 **+ 气象动效**（雨丝/飘雪/流云）+ 光感按压弹性；统一受"克制"约束 |
| 图标 | 单一 SF Symbols 语义层 | 天气符号支持**阴影/渐变/快速替换动效（SymbolGlyph）**，昼夜双光影 |
| 个性 | 中性、去风格化，让 App 内容定义个性 | **天空即品牌**：每个城市是一片独立的天空，个性来自天气本身而非装饰 |

### 3.1 一句话总结改进
> 苹果的界面是**中性而安静的画布**；卷云的界面是**有天气的、会呼吸的天空**——同样是"让内容说话"，但我们的"内容"是天气，"画布"是大气。

### 3.2 我们**刻意不做**的事（与苹果精神一致）
- 不做装饰性无意义动效；不做拟物化的假材质贴图。
- 不让背景色污染信息层级；不牺牲对比度换取"通透"。
- 不因追求氛围而改变信息结构与交互路径（跨设备一致）。

## 4. 设计语言五要素：光 · 色 · 形 · 字 · 动

### 4.1 光（Light）
- **载体**：沉浸光感材质（标题栏 / 底部导航 / 弹窗 / 内容卡）。
- **档位**：`ADAPTIVE`（默认，随算力自适应）→ `EXQUISITE`（高算力）→ `GENTLE`（中）→ `SMOOTH`（低）；用户可在设置中手动降/升。
- **语言**：通透（毛玻璃）、反馈（按压点光源/弹性）、流动（材质流光）、自适应（智能反色）。
- **红线**：同屏材质控件数量受控；滚动期暂停粒子动效（GPU 开销叠加）。

### 4.2 色（Color）
- **动态天空主题**：主色 = `f(天气状况, 时段, 昼夜)`。晴昼暖蓝→金、晴夜深蓝→靛、雨青灰、雪冷白蓝、雷暴紫灰。
- **语义色**承担功能，主题色承担氛围；二者分离，保证信息可读。
- **取色确定性优先**：v1 不采用壁纸动态取色（Material You），改由天气驱动，保证"截图可知天气"的可预测性。

### 4.3 形（Form）
- 圆角语言：卡片 16–24vp，浮层/胶囊为全圆角，与系统圆角语言一致。
- 留白即呼吸：以留白替代分隔线，以材质层级替代描边。
- 悬浮胶囊导航替代贴底 TabBar，让内容从导航"下方流过"。

### 4.4 字（Typography）
- 字体：HarmonyOS Sans（系统字体，不引入外部字体，控体积 + 无障碍对齐）。
- 层级：Hero 温度 64–96vp（Light/Thin，轻盈）→ 标题 20–24vp → 正文 14–16vp → 辅助 12vp。
- 数字即图形：温度用**数字翻牌**动效刷新，用**渐变文本**增强体感。
- 支持系统字体缩放 1.5× 不破版。

### 4.5 动（Motion）
- 三大类：**气象动效**（背景粒子）、**光感动效**（按压弹性/点光源）、**转场动效**（共享元素、数字翻牌）。
- 统一原则：**克制、可解释、可关闭**。`prefers-reduced-motion` 时仅保留必要过渡。
- 时长与曲线：主转场 200–300ms 标准缓动；弹性反馈用物理弹簧（spring）。

## 5. 视觉标尺（Design Tokens 基线）

| 类别 | Token | 取值 |
|------|-------|------|
| 间距 | space-1/2/3/4/6/8 | 4 / 8 / 12 / 16 / 24 / 32 vp |
| 圆角 | radius-card / sheet / pill | 20 / 28 / 全圆角 vp |
| 层级 | elevation-0/1/2 | 背景 / 内容卡 / 浮层（材质与阴影递进） |
| 字号 | display / title / body / caption | 72 / 22 / 15 / 12 vp |
| 字重 | hero / label | Light / Medium |
| 材质 | material-tier | ADAPTIVE（默认）/ EXQUISITE / GENTLE / SMOOTH |
| 动效 | dur-fast / dur-base | 150 / 250 ms |

> 阴影视具体情况以**沉浸光感材质自带阴影**为主（`applyShadow`），避免自绘阴影与系统材质冲突。

## 6. 气象拟真主题矩阵（动态皮肤）

主色与背景渐变由「天气 × 时段」推导（示例，最终以真机调色为准）：

| 状况 | 昼（Day） | 夜（Night） | 晨昏（Dawn/Dusk） |
|------|-----------|-------------|-------------------|
| 晴 | 暖蓝 → 金 | 深蓝 → 靛 | 橙 → 紫 |
| 多云 | 灰蓝 → 白 | 墨蓝 → 灰 | 灰金 → 蓝 |
| 雨 | 青灰 → 深青 | 深青灰 → 墨 | 冷灰 → 蓝 |
| 雪 | 冷白蓝 → 灰白 | 深蓝白 → 靛 | 淡紫 → 冷灰 |
| 雷暴 | 紫灰 → 深灰 | 深紫黑 → 墨 | 暗金 → 紫黑 |
| 雾 | 灰白 → 浅灰 | 深灰 → 墨 | 灰 → 淡蓝 |

**可读性护栏**：无论何种主题，文字与背景对比度 ≥ 4.5:1；前景接近底色时由**智能反色**自动兜底。

## 7. 组件语言

| 组件 | 设计语义 | 材质/光感 |
|------|----------|-----------|
| Hero 大温度 | 首屏唯一主角 | 通透背景 + 数字翻牌 + 渐变字 |
| 玻璃内容卡 | 承载分组信息 | 稳定玻璃（`backgroundBlurStyle`）；标题栏/导航用沉浸光感 |
| 悬浮胶囊导航 | 空间化的交互载体 | 沉浸光感材质 + MiniBar + 智感握姿 |
| 标题栏 | 随滑动呼吸 | 渐变模糊（`GRADIENT_BLUR`/`IMMERSIVE_GRADIENT_BLUR`）+ 动态显隐 |
| 弹窗/菜单 | 全页面生效的材质 | `systemMaterial(ImmersiveMaterial)` |
| 天气符号 | 语义 + 动效 | SymbolGlyph，昼夜双光影 |

> ⚠️ **官方约束（决定材质落点）**：`ImmersiveMaterial` 对普通内容区组件**不生效**，仅在 *Navigation/NavDestination 标题栏* 与 *横向 Tabs `barPosition=BarPosition.End` 的底部 TabBar* 中生效；弹窗类组件、`Slider`、`Toggle`、`Select` 可在全页面生效。**因此内容区卡片仍采用稳定的 `backgroundBlurStyle` 玻璃**，沉浸光感聚焦于标题栏、底部导航与弹窗。（修正见 [11](./11-鸿蒙新特性与沉浸光感适配.md) §2.2）

## 8. 多设备一致性

- **同一语言，不同器物**：手机=单手轻触；平板=主从分栏；PC=多窗并行；TV=焦点大屏；手表=一瞥即读。
- **一致优先级**：结构与交互一致 > 视觉一致。氛围可因设备算力分级（材质档位），但**信息架构不变**。
- 宽屏底部悬浮导航**智感握姿**左右跟随；窄屏自动折叠 MiniBar。

---

## 9. 无障碍与克制

- 最小对比度 4.5:1；不依赖纯颜色传达信息（天气/预警同时用文字+图标）。
- 图标配 `accessibilityLabel`（如「晴，24 度」）。
- 支持屏幕朗读、字体缩放、高对比；`prefers-reduced-motion` 时收敛动效。
- 氛围永远服从可读性：**当冲突时，牺牲氛围，保信息。**

## 11. ⚠️ 待确认项（须真机核实）

1. `HdsNavigation.titleBar` / `dynamicHideTitleBar` / `bindToScrollable` 在 API 26 的**精确签名**与组合约束（需 DevEco Studio 编译期校验）。
2. 沉浸光感材质在不同算力档位下的**具体调色**，须在真机（模拟器不支持 HDS 沉浸视效）上定稿。
3. 内容区卡片若未来要材质，需回到官方确认是否有更新（当前判定：不生效）。
4. 出海版本的视觉降级（UI Design Kit 仅中国境内）：境内走 HDS，境外回落普通 ArkUI + `backgroundBlurStyle`。
5. 气象粒子动效的性能预算与低端机/手表的降级阈值。

## 12. UI 修正记录（本轮）

| 问题 | 根因 | 修正 |
|------|------|------|
| 位置页选项点不动、布局简陋 | 根容器缺 `height('100%')` → 内部 `List.layoutWeight` 折叠，命中区域错位 | 根容器补 `height('100%')`；列表项改为可点选卡片（选中态高亮 + 默认标签 + 删除/设默认） |
| 定位后未出现所在城市 | 生成的位置 `name` 为空、id 随坐标变化导致去重失效 | id 固定为 `current`；名称为空时回退本地化标签「当前位置」 |
| 设置页菜单从左侧弹出 | `bindMenu` 默认锚定行容器左缘 | `bindMenu(menu, { placement: Placement.BottomRight })` |
| 天气页信息简陋、字体平淡 | 字号层级弱、更新时间显示为时间戳、缺少分区 | Hero 温度 88vp/图标 52vp；高低温+体感行；更新时间用 `DateTimeUtil.formatHour`；分区卡片（逐时 chips / 逐日列表 / 详情指标网格） |
| 折叠屏展开右侧留白 | `HdsNavigation` 展开态默认分栏（Split），内容挤在左导航栏 | 显式 `.mode(NavigationMode.Stack)` |
| 顶部状态栏白色突兀、底部留白 | 未开启沉浸式全屏 | `setWindowLayoutFullScreen(true)` + 透明状态/导航栏 + 内容色随深浅色自适应；内容区 `expandSafeArea(TOP,BOTTOM)` |

> ⚠️ 沉浸式安全区（顶部 44 / 底部 96 内边距）与 HDS 悬浮导航的叠加需真机微调。
