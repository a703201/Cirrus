# Cirrus（卷云）· 鸿蒙天气应用 —— 项目规划文档集

> 参考设计：Breezy Weather、Geometric Weather
> 平台：HarmonyOS NEXT（ArkTS + ArkUI）
> 项目代号：**Cirrus（卷云）** ｜ 包名建议：`com.cirrus.weather`

## 立项关键决策（已确认）

| 维度 | 决策 |
|------|------|
| 天气数据源 | **多源可插拔**：默认 Open-Meteo（免密钥），预留和风天气 / 彩云等扩展接口 |
| 目标设备 | 手机、平板、折叠屏、智能手表、电脑（PC）、电视（TV）全场景 |
| 多语言 | 广泛多语：zh-CN / en-US / ja-JP / ko-KR / fr-FR / es-ES / de-DE 等 |
| 最低 API | **API 26**（用户指定最新稳定版），compile / target / minSdk 统一 26 ｜ HarmonyOS NEXT |
| 架构模型 | Stage 模型 + ArkUI 声明式（**状态管理 V2**）；离线优先 + 跨设备分布式同步 |
| 新特性基调 | **大量适配鸿蒙新特性**：以 **UI Design Kit（HDS）+ 沉浸光感（空间化）** 为第一眼视觉基石；原生框架，Kit 化导入 |
| 视觉基调 | **沉浸光感 / 空间化**：系统材质毛玻璃 + 悬浮胶囊导航 + 智感握姿；替代自研 blur 卡片 |

**v1 范围已锁定**：TV 与手表纳入首版；国内源（和风天气等）启用前必须完成合规资质与隐私条款补全；首发即 7 语种（zh-CN / en-US / ja-JP / ko-KR / fr-FR / es-ES / de-DE）全量。目标 API 级别：**26**。

> 新特性与沉浸光感适配的完整结论、约束与降级策略见 [11-鸿蒙新特性与沉浸光感适配](./11-鸿蒙新特性与沉浸光感适配.md)（含「实况窗/意图框架不适用或受限」等重要判定）。

## 文档约定

- 所有接口字段、权限名、API 级别以 **HarmonyOS 官方文档（developer.huawei.com）** 为最终依据；文中标注「⚠️ 待确认」处需在立项/编码前核实最新 API 级别与 Kit 可用性。
- 新特性接入统一遵循 `11` 号文档：**Kit 化导入（`@kit.*`）**、**状态管理 V2（新代码）**、**沉浸光感优先 + 能力探测降级**。
- 代码片段为 **ArkTS** 示意，展示架构意图，非可直接运行的生产代码。
- 单位约定：温度摄氏度（°C）、风速以 km/h 与 m/s 双标、气压 hPa、降水 mm。
