# 隐私与权限合规（Cirrus / 卷云）

> 原则：数据最小化、位置仅用于天气查询、默认免密钥源、流向透明、合规可审计。

## 1. 数据最小化

| 数据类型 | 是否收集 | 用途 | 存储 |
|----------|----------|------|------|
| 精确/近似位置 | 仅授权时 | 反查城市并请求天气 | 本地，不上传第三方（除天气源查询） |
| 天气数据 | 是（来自源） | 展示 | 本地 RDB 缓存 |
| 用户设置 | 是 | 个性化 | 本地 Preferences / DistributedKV |
| 崩溃日志 | 可选，默认关 | 排障 | 本地，不上报（无遥测为默认） |
| 身份/账号 | 否 | — | — |

- **不收集**通讯录、相册、麦克风、摄像头、IMEI 等无关信息。
- **无广告、无第三方分析 SDK**（默认），杜绝隐蔽上传。

## 2. 位置权限说明（按需申请）

| 权限 | 级别 | 申请时机 | 理由 |
|------|------|----------|------|
| `ohos.permission.LOCATION` | 敏感 | 用户点击「定位我的位置」时 | 获取当前位置天气 |
| `ohos.permission.APPROXIMATELY_LOCATION` | 粗粒度（API 11+） | 同上，优先申请此粗粒度 | 天气只需城市级精度，降低隐私暴露 |

- **前置告知**：申请前弹「为何需要位置」说明；提供「仅此次/始终/拒绝」并说明拒绝后可用城市搜索替代。
- **可关可审**：设置页「数据流向」列出：位置 → 所选天气源（HTTPS）；不共享给其他方。

## 3. 第三方数据源共享边界

- 位置（经纬度）仅发送给**用户当前所选天气源**用于查询，不附加设备标识/账号。
- 免密钥源（Open-Meteo）不要求密钥，最小化关联。
- 扩展源（如和风天气）需密钥时：
  - 密钥存于本地 `Preferences`（设备加密），不进代码/不上报；
  - 在隐私政策明确列出该源及其数据收集行为；
  - 用户可随时切回免密钥源。

### 3.1 国内源（和风天气等）合规前置清单（启用前必完成）
- [ ] 核实服务商资质与实名 / 备案要求，确认其允许本应用分发地区使用；
- [ ] 在隐私政策新增章节，列明该源名称、收集的数据（位置 / 查询记录）、用途与保留期限；
- [ ] 设置页「数据源」中该源默认**关闭**，由用户主动开启并二次确认告知；
- [ ] 密钥仅存本地 `Preferences`（设备加密），不硬编码、不上报；
- [ ] 通过 `harmonyos-reviewer` 编码审查 + 法务评审；未通过将源降级为「实验性 / 隐藏」，不得默认启用。

## 4. 合规要求

| 事项 | 要求 |
|------|------|
| 隐私政策 | 上架前必备，明示收集项、用途、第三方共享、用户权利 |
| 国内商用源（和风等） | 关注服务商实名/备案要求；若在中国大陆分发，确认源资质与数据跨境 |
| 未成年人 | 不主动收集未成年人专属信息；若涉收集需监护人同意（按法规） |
| 跨境（多语/出境） | 用户城市可能为境外；默认源全球覆盖，注意当地隐私法规（GDPR 等）仅作提示 |
| 权限声明 | `module.json5` 中声明所需权限并配置 `reason` 与 `usedScene` |

## 5. 权限清单（汇总）

| 权限 | 必要性 | 设备 | 说明 |
|------|--------|------|------|
| `ohos.permission.INTERNET` | 必需（联网取数） | 全设备 | 直连天气源 |
| `ohos.permission.LOCATION` / `APPROXIMATELY_LOCATION` | 可选（定位天气） | 手机/平板/手表 | 优先粗粒度，按需申请 |
| `ohos.permission.KEEP_BACKGROUND_RUNNING` | **不需要**（修正） | — | 该权限用于**长时任务**；天气周期刷新用**延迟任务**（WorkScheduler），无需声明 |
| 通知 | 摘要/预警（运行时用户授权） | 手机/平板/手表 | 无需声明权限，`requestEnableNotification` 授权 |
| Push Kit（AGConnect） | 预警推送 | 手机/平板 | 需 AGC 配置与推送权益 |

> 所有敏感权限**按需、分时申请**，不在启动时一次性索要；拒绝后功能降级而非崩溃。
> **权限最小化红线**：不声明与主流程无关的权限；`KEEP_BACKGROUND_RUNNING`、实况窗权益等**一律不声明/不申请**（见下）。

## 6. ⚠️ 待确认项
- 若启用和风等国内源，确认其最新合规资质与隐私条款，并据此补全隐私政策条款。
- 是否在个别市场（如欧盟）默认关闭所有网络源以外行为，提供「纯本地」模式。
- 崩溃日志策略最终决定（默认不收集）。
- **地域性系统能力**（合规相关）：UI Design Kit / 沉浸光感、Live View Kit 实况窗、Intents Kit 意图框架**均仅中国境内**；出海分发须关闭对应能力并在隐私政策说明能力降级。
- **实况窗（Live View Kit）与意图框架（Intents Kit）已判定不纳入主流程**（前者天气场景不适用、后者仅企业开发者），故**不申请相关权益**，避免过度合规负担。详见 `11` §6.4/§6.5。
