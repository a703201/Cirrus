# 研发计划与质量保障（Cirrus / 卷云）

> 周期基线：约 20 周（可按团队规模并行压缩）｜ 目标 API：26（用户指定最新稳定版）

## 1. 里程碑

| 阶段 | 周期 | 目标交付 |
|------|------|----------|
| M1 立项与架构 | 2 周 | 决策确认、架构设计、UI 原型、文档基线 |
| M2 数据层 + 默认源接入 | 3 周 | `WeatherRepository` + Open-Meteo 源 + RDB 缓存 + Geocoding |
| M3 核心 UI（手机）+ **HDS 框架接入** | 4 周 | Home/Hourly/Daily/Details/Locations/Settings（sm 布局）；**HdsNavigation/HdsTabs 骨架 + 沉浸光感首眼**；状态管理 V2 起步 |
| M4 多设备适配 | 3 周 | 折叠/平板/PC 主从布局、断点、智感握姿、TV 焦点导航、手表独立入口 |
| M5 卡片 + 通知 + 预警 | 3 周 | FormExtension 卡片、每日摘要、Push Kit 预警 |

> **新特性专项**（沉浸光感/HDS、状态管理 V2、一多部署对齐）横跨 M3–M6，详见 `11-鸿蒙新特性与沉浸光感适配.md`。

## 3. 测试策略

### 3.1 单元测试（Hypium）
- 数据解析：`OpenMeteoSource.toNormalized()` 对样例响应断言。
- WMO 映射：代码→图标键/文案全覆盖（接口文档 §3.5）。
- 单位换算：visibility(m→km)、风速单位等边界值。
- 缓存策略：过期判定、键唯一性。

### 3.2 UI 自动化（uitest）
- 主流程：定位/搜索 → 展示 → 刷新 → 切换位置 → 设置切换源。
- 异常流：断网回退缓存、权限拒绝降级、源切换清缓存。

### 3.3 多设备矩阵
| 设备 | 必测 |
|------|------|
| 手机 | 全主流程 + 权限 |
| 折叠屏 | 展开/收起重排无错位 |
| 平板/PC | 主从布局、窗口缩放 |
| TV | 焦点导航、大字可读 |
| 手表 | 并发症 + 极简卡片 |

### 3.4 性能
- 冷启动首屏 ≤ 1.0s（缓存命中）；完整数据 ≤ 2.0s（P95）。
- 内存：后台无泄漏（fd/定时器/监听在 `aboutToDisappear` 清理）；可用 Performance Analysis Kit 资源泄露检测辅助。
- 帧率：列表/图表滑动 ≥ 50fps；**沉浸光感开启后同屏材质控件数与帧率须真机测量**。
- 包体积：初始 ≤ 25MB。

### 3.5 新特性专项验证（新增）
- **材质降级**：低端设备/模拟器下 `getSystemMaterialTypes()` 为空时界面正常（不白屏、不卡顿）。
- **沉浸光感真机验收**：标题栏渐变模糊、悬浮导航胶囊、按压点光源/弹性反馈（模拟器不支持，须真机）。
- **智感握姿**：宽屏左右手握持时悬浮导航跟随切换。
- **TV 焦点**：方向键走焦顺序、环绕（`focusWrapMode`）、无滚动长页。
- **状态管理 V2**：无 V1/V2 装饰器混用违规；`AppStorageV2/PersistenceV2` 持久化正确。

## 4. 质量门禁

- **编码审查**：`harmonyos-reviewer` 编码期合规审查（组件/API/权限/版本）先于自动化测试。
- **新特性合规**：Kit 化导入（`@kit.*`）、沉浸光感能力探测降级、状态管理 V2 无混用违规、实况窗/意图框架不被误接入。
- **构建闸门**：统一 `build_hap.sh`（或 hvigor）零 ERROR 方可提交。
- **Lint/类型**：ArkTS 红线（禁 `any/unknown`、组件 getter 等）CI 拦截。
- **测试门禁**：单测 + 核心 uitest 全绿；设备矩阵关键用例通过；新特性专项（§3.5）通过。
- **文档同步**：版本号/接口变更同步全部规划文档并独立分章。

## 5. 发布流程（AppGallery）

1. 完成 M7 测试与隐私政策。
2. 配置签名与 `module.json5` 权限 `reason/usedScene`。
3. 构建 Release HAP/APP，过华为审核（资质/隐私/内容）。
4. 分阶段发布（先小流量），监控崩溃与反馈。
5. 多语商店页（7 语种显示名 + 截图）同步上线。

## 6. 风险与缓解

| 风险 | 影响 | 缓解 |
|------|------|------|
| 国内 Open-Meteo 访问不稳定 | 数据延迟/失败 | 内置缓存兜底 + 预留和风等国内源快速切换 |
| 多设备适配工作量超预期 | 进度延误 | M4 覆盖手机/平板/PC/TV/手表；遥控器焦点与手表并发症排期前置，必要时裁剪次要动效 |
| 扩展源合规不确定性 | 上架受阻 | 已设合规前置硬门禁（资质+隐私条款+默认关闭+评审），未过审源不启用（见隐私文档 §3.1） |
| 手表/ TV Kit 受限 | 功能缩水 | 独立轻量入口，降级而非阻塞 |
| 多语文案质量 | 体验/合规 | 关键语种专业审校 + 上线前 key 完整性 CI |
| UI Design Kit/沉浸光感**仅中国境内**且材质仅 Phone/Tablet | 出海包无法用 HDS | `common/ui` 抽象材质层，境外/不支持设备降级普通 ArkUI（见 11 §8） |
| 沉浸光感 GPU 开销 | 低端机卡顿/发热 | 强制 `ADAPTIVE` + 能力探测 + 滚动期暂停粒子 + 同屏材质控件上限 |
