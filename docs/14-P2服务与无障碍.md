## 1. P2-1 数据源扩展：空气质量 + 气象预警

### 模型（common）
`WeatherData` 增可选字段：`airQuality?: AirQuality`、`alerts?: WeatherAlert[]`；结构见 `common/src/main/ets/models/WeatherData.ts`。

### 数据源（data）
| 源 | 空气质量 | 预警 | 说明 |
|----|----------|------|------|
| Open-Meteo | ✅ `air-quality-api.open-meteo.com`（US AQI / PM2.5 / PM10） | — | 默认源，免 Key |
| 和风 QWeather | ✅ `/v7/air/now` | ✅ `/v7/warning/now` | 需 API Key（合规门禁） |

- 空气质量与预警均为 **best-effort**：单独 try/catch，失败返回 `undefined`，不影响主天气流程。
- 和风源启用：在 `data/src/main/ets/sources/QWeatherConfig.ets` 填入 `QWEATHER_API_KEY`；为空时 `enabledByDefault=false`、调用抛错。

### UI（entry）
- 详情页 `DetailsPage`：新增 AQI / PM2.5 / PM10 / 空气质量等级卡。
- 预警页 `AlertsPage`：列出 `WeatherData.alerts`（等级 + 标题 + 描述），并接入底部页签「预警」。

## 2. P2-2 本地通知（`@kit.NotificationKit`）

`entry/src/main/ets/notify/NotificationUtil.ets`：

| 能力 | 触发 | 去重 |
|------|------|------|
| 每日摘要 | 天气刷新成功后 | 同一天仅一次 |
| 预警通知 | `alerts` 集合变化时 | 以标题集合为键去重 |

- 首次进入经 `requestEnableNotification` 申请授权；用户拒绝后静默。
- 通知内容使用基础文本类型（`NOTIFICATION_CONTENT_BASIC_TEXT`）。

## 3. P2-3 预警推送（`@kit.PushKit`）

`entry/src/main/ets/push/PushService.ets` 提供取 Token 脚手架（`pushService.getToken()`），在 `EntryAbility.onCreate` 调用。

**AGC 侧待办（发布前）**：
1. 在 AppGallery Connect 创建应用并开启「推送服务」。
2. 配置签名证书指纹，绑定应用包名 `com.Lumio.Cirrus`。
3. 服务端按 topic 下发预警，客户端按需订阅。
4. 如需前台接收，接入 `RemoteNotificationExtensionAbility` 并在 `module.json5` 声明（⚠️ 待接入，需真机/AGC 联调验证）。

> 未完成 AGC 配置时，`getToken()` 失败被捕获并记录，应用正常运行。

## 4. P2-6 无障碍增强

| 维度 | 措施 | 落点 |
|------|------|------|
| 朗读标签 | 天气卡合并朗读（温度 + 天气现象）；逐时项朗读（时间+温度+降水概率）；预警项完整朗读；设置项按行分组朗读，装饰性「▾」设 `accessibilityLevel('no')` | `WeatherCard`、`HourlyPage`、`AlertsPage`、`SettingsPage` |
| 对比度 | 次要文字由 `#6B6B6B` 提升至 `#595959`（浅色背景下对比度 ≥ 4.5:1） | `DetailsPage`、`HourlyPage` |
| 字体缩放 | 字号使用 `fp`（ArkUI 数字默认 `fp`），随系统字体缩放；容器为弹性布局，不裁剪 | 全局 |

> ⚠️ 待真机用「屏幕朗读 + 大字号 + 高对比」回归验证。

## 5. P2-7 数据流向说明 + 隐私政策内嵌

`entry/src/main/ets/features/settings/PrivacyView.ets`，从设置页「数据与隐私」行进入（内嵌切换，不依赖路由，离线可读）。页面按 [09-隐私与权限合规](./09-隐私与权限合规.md) §1~§4 合规矩阵组织为四张卡片 + 页脚注记：

| 分区 | 资源键 | 内容要点 |
|------|--------|----------|
| 数据流向 | `privacy_data_flow_title` + `privacy_flow_*`（5 条） | 离开设备的数据（仅粗略坐标经 HTTPS 送所选源，不附加设备标识/账号/广告 ID）；留存本机（RDB 天气缓存 + Preferences 设置）；跨设备同步（可选，分布式 KV）；预警推送（可选，Push Kit + 数据提供方）；无遥测与广告 |
| 权限使用 | `privacy_permissions_title` + `privacy_perm_*`（3 条） | 与 `module.json5` 声明一致：INTERNET 必需；LOCATION / APPROXIMATELY_LOCATION 可选按需（粗略优先）；通知运行时授权 |
| 第三方数据源 | `privacy_third_party_title` + `privacy_third_*`（2 条） | Open-Meteo 默认免密钥、仅收查询坐标；和风天气可选、API Key 仅本机加密存储、默认关闭、可随时切回 |
| 隐私政策 | `privacy_policy_title` + `privacy_policy_*`（6 条） | 收集范围 / 存储与删除 / 用户权利 / 未成年人 / 跨境使用 / 联系方式 |
| 页脚注记 | `privacy_meta_note` | 版本 v1.0、更新月份、随应用内置离线可读、发布前法务复核 |

- 8 语种均已补齐上述键（base / zh-CN / en-US / ja-JP / ko-KR / fr-FR / es-ES / de-DE），键集合八语种完全一致（脚本化写入 + 集合校验）。
- 条目行整行 `accessibilityGroup(true)` 合并朗读，次要文字 `#595959`（对比度 ≥ 4.5:1，接 P2-6）。
- ⚠️ 正式上线前须以法务终稿复核全部文案（当前联系方式为占位），并与 [09-隐私与权限合规](./09-隐私与权限合规.md) 保持一致。

## 6. 验证清单（DevEco Studio / 真机）

1. 详情页在 AQI 可用时展示空气质量卡；不可用时该行隐藏。

4. 未配置 AGC 时 `PushService.init()` 仅告警不崩溃。
5. 屏幕朗读能完整读出天气卡与逐时项；大字号下不破版。
